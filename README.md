# AI 大模型面试刷题 APP

把面试备考知识点当「题」来刷的纯前端小工具，**零依赖、零联网、不装任何环境**，双击即用。

> 数据源：本文件夹内的 `01 背诵宝典` / `03 HR一面` / `04 技术二面`，共 **135 题**。

---

## 📁 三个文件

| 文件 | 作用 |
|------|------|
| `index.html` | 刷题界面（打开它就能用） |
| `data.js`  | 全部题目数据（想增删 / 改答案只动这个） |
| `README.md` | 本说明 |

> 进度（已掌握、待复习、连胜、续学位置、深色模式、春招目标日等）全部存在**本机浏览器 localStorage**，换电脑不共享；清浏览器缓存会一起清空。

---

## 🚀 怎么打开

**最简单**：直接双击 `index.html`，用浏览器（Chrome / Edge / 360 都行）打开即可。

> 如果浏览器因本地安全策略拦截 `data.js`（极少数情况），在本文件夹打开终端跑一个小服务器即可：
> ```bash
> # Python 3
> python -m http.server 8000
> # 然后浏览器访问 http://localhost:8000/index.html
> ```

## 🎯 功能用法

### 筛选与查找
- **分类筛选**（12 类）：大模型原理基础 / RAG / Agent / Prompt工程 / LangChain与工程框架 / 工程落地 / 微调·量化·部署·AIGC / Python与机器学习基础 / 企业面试技巧与高频综合题 / 自我介绍逐字稿 / HR一面 / 技术二面。
- **星级筛选**：按高频程度（⭐⭐⭐⭐⭐ 必背 / ⭐⭐⭐⭐ / ⭐⭐⭐ 及以上）快速锁定重点。
- **搜索**：输入关键词（如 `RAG`、`LoRA`、`薪资`、`死循环`）即时过滤，题目 / 答案 / 流程里出现即命中。
- **模式**：顺序刷题 / 只看待复习 / 未学习 / 已掌握。

### 看题与背诵
- **显示答案**：每题答案分两块——
  - **流程描述**：用 `-->` 串联的骨架，先记步骤；
  - **背诵文段**：一段可直接口述的话。
- **卡片右上角**会显示该题「下次复习：X 天后 / 今天」。

### 🧠 间隔重复（SM-2，仿 Anki）
不再是简单的「标掌握」，而是按记忆曲线排复习：
- 看完答案后点四个评分按钮之一：
  - 🔴 **忘记**（没记住）→ 明天重学；
  - 🟠 **困难** → 间隔小幅增长；
  - 🟢 **良好** → 间隔按难度系数增长；
  - 🔵 **简单** → 间隔增长最多。
- 算法自动算出**下次复习日期**（首次良好→1 天，再良好→6 天，之后越来越长），到点才会出现在「只看待复习」里。
- 顶栏实时显示 **「· 待复习 N」**；「已掌握」指已毕业（连对 2 次以上）的题。

### 📅 春招倒计时复习计划
- **顶栏倒计时**：「📅 距春招 N 天」，默认目标日 `2027-03-15`，**点一下可改日期**（输 `YYYY-MM-DD`）。
- **今日计划条**（工具栏下方）：自动汇总「复习 X 道（按分类拆解）· 新学 Y 道」，**点条尾「(改额度)」可改每天新学题数**（默认 5）。

### ↪ 续学（记住上次位置）
- 翻题 / 评分 / 随机 / 切换筛选时会自动记住「当前题 + 当前筛选」。
- 关掉网页再打开，**直接回到上次那道题、且筛选条件和退出时一致**。
- 想从头开始新一轮，点「↺ 重置进度」即可。

### 🌙 深色模式
- 顶栏右上角「🌙 深色」一键切换，选择记在浏览器，下次打开还是你上次的主题。

### 其它
- **随机一题 / 重置进度** 按钮。
- 进度自动保存，无需手动操作。

## 📝 每题的数据结构

`data.js` 里是一个 `QUIZ_DATA` 数组，每题长这样：

```js
{
  id: 14,                 // 题号（唯一）
  cat: "二、RAG",          // 分类
  stars: 5,               // 高频程度 1~5
  q: "RAG 完整链路如何设计、各环节耗时瓶颈",  // 题目
  flow: "离线入库：文档解析→智能分块→向量化→写向量库 --> 在线检索：Query改写→向量检索→重排→拼Prompt ...", // 流程描述（--> 分隔）
  ans: "RAG 分三阶段：离线入库是……（一段背诵文段）"  // 背诵文段
}
```

- `flow` 里的 `-->` 在界面里会自动渲染成 `→` 箭头，方便按步骤背。
- 想改某题答案，**只改 `data.js` 里对应那一条的 `flow` / `ans` 即可**，保存后刷新页面生效。

## ➕ 怎么加题 / 改分类

1. 打开 `data.js`。
2. 在 `QUIZ_DATA = [ ... ]` 末尾（最后一个 `}` 之后、 `];` 之前）加一条新对象，逗号分隔。
3. 若要新分类出现在下拉框，把分类名加进文件底部的 `CATEGORY_ORDER` 数组即可。
4. 保存，刷新 `index.html`。

## 💡 刷题建议（结合你的宝典）

1. 先把所有 **⭐⭐⭐⭐⭐** 吃透（占面试 60% 分值），再攻 ⭐⭐⭐⭐（25%）。
2. 每题先背「流程描述」骨架，再用「背诵文段」口述一遍，2~3 分钟一道。
3. **用间隔重复代替一次性背完**：每天点开先刷「只看待复习」，把快忘的题按曲线巩固，远比考前突击扎实。
4. 配合 2 个能讲清细节的项目（MediGraph 医药知识图谱 / 本草君 中医药 RAG），HR / 技术面那 28 题就是为你量身准备的「追问弹药」。
5. 诚实边界：被问到深度实现，说「整体架构和原理我清楚，关键模块基于 LangChain/LangGraph 框架和 AI 辅助编程完成，设计思路能讲清」——比硬编安全。
