# AI 大模型面试刷题 APP

把面试备考知识点当「题」来刷的纯前端小工具，**零依赖、零联网、不装任何环境**，双击即用。

> 数据源：本文件夹内的 `01 背诵宝典` / `03 HR一面` / `04 技术二面`，共 **137 题**。

---

## 📁 三个文件

| 文件 | 作用 |
|------|------|
| `index.html` | 刷题界面（打开它就能用） |
| `data.js`  | 全部题目数据（想增删/改答案只动这个） |
| `README.md` | 本说明 |

---

## 🚀 怎么打开

**最简单**：直接双击 `index.html`，用浏览器（Chrome / Edge / 360 都行）打开即可。

> 如果浏览器因本地安全策略拦截 `data.js`（极少数情况），在本文件夹打开终端跑一个小服务器即可：
> ```bash
> # Python 3
> python -m http.server 8000
> # 然后浏览器访问 http://localhost:8000/index.html
> ```

## 🎯 功能用法

- **分类筛选**：大模型原理 / RAG / Agent / Prompt / LangChain / 工程落地 / 微调量化 / Python基础 / 面试技巧 / 毕设 / HR一面 / 技术二面。
- **星级筛选**：按高频程度（⭐⭐⭐⭐⭐ 必背 / ⭐⭐⭐⭐ / ⭐⭐⭐ 及以上）快速锁定重点。
- **搜索**：输入关键词（如 `RAG`、`LoRA`、`薪资`、`死循环`）即时过滤。
- **模式**：顺序刷题 / 只看未掌握 / 只看已掌握。
- **显示答案**：每题答案分两块——
  - **流程描述**：用 `-->` 串联的骨架，先记步骤；
  - **背诵文段**：一段可直接口述的话。
- **标记掌握**：标记后进度条实时更新，进度存在本机浏览器（换电脑不共享）。
- **随机一题 / 重置进度** 按钮。

### 快捷键
| 键 | 作用 |
|----|------|
| `空格` | 显示 / 隐藏答案 |
| `←` `→` | 上一题 / 下一题 |
| `M` | 标记为已掌握 |

## 📝 每题的数据结构

`data.js` 里是一个 `QUIZ_DATA` 数组，每题长这样：

```js
{
  id: 14,                 // 题号（唯一）
  cat: "二、RAG",          // 分类
  stars: 5,               // 高频程度 1~5
  q: "RAG 完整链路如何设计、各环节耗时瓶颈",  // 题目
  flow: "离线入库：文档解析→智能分块→向量化→写向量库 --> 在线检索：Query改写→向量检索→重排→拼Prompt ...", // 流程描述（--> 分隔）
  ans: "RAG 分三阶段：离线入库是……（一段背诵文段）"  // 背诵文段
}
```

- `flow` 里的 `-->` 在界面里会自动渲染成 `→` 箭头，方便按步骤背。
- 想改某题答案，**只改 `data.js` 里对应那一条的 `flow` / `ans` 即可**，保存后刷新页面生效。

---

## ➕ 怎么加题 / 改分类

1. 打开 `data.js`。
2. 在 `QUIZ_DATA = [ ... ]` 末尾（最后一个 `}` 之后、 `];` 之前）加一条新对象，逗号分隔。
3. 若要新分类出现在下拉框，把分类名加进文件底部的 `CATEGORY_ORDER` 数组即可。
4. 保存，刷新 `index.html`。
